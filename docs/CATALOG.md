## Antes del lanzamiento comercial

- Confirmar que cada precio sigue vigente y cada producto está disponible.
- Aclarar qué significa cada medida de maceta y si el tamaño representa planta, maceta o ambas cosas.
- Confirmar si las promociones incluyen una o más Droseras y hasta cuándo rigen.
- Definir retiro, zonas de entrega, costo de envío y cuidados durante el traslado.
- Reemplazar o actualizar las publicaciones cuando cambie la planta exacta que recibirá el cliente.
