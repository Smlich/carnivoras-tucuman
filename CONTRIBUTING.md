# Cómo trabajar en este repositorio

## Ciclo de aprendizaje

1. Elige un cambio pequeño del cronograma.
2. Crea una rama con un nombre descriptivo, por ejemplo `feat/catalog-search` o `docs/first-session`.
3. Haz commits pequeños que describan una sola intención: `feat: agrega filtros al catálogo`, `fix: conserva cantidades del carrito` o `docs: explica el flujo de pedido`.
4. Revisa el cambio en el navegador y ejecuta `npm run build`.
5. Abre un pull request con el resumen, el impacto para el cliente, cómo se revisó y qué aprendiste.

## Reglas de colaboración

- Mantén la interfaz en español y el código con nombres claros.
- Nunca subas contraseñas, tokens, secretos OAuth ni datos personales de clientes.
- Confirma stock y precios con el negocio antes de anunciar cambios.
- Usa fotos autorizadas del catálogo; evita ilustraciones que puedan confundirse con el producto real.
- Si extraes un componente o una utilidad nueva, explica su responsabilidad en el pull request.
